Home Planner Privacy Policy

Last updated October 15, 2026.

Home Planner is a private tool used by one household. This policy explains what it does with Google user data.

What Google data it uses

Home Planner asks for one Google permission, which lets it create its own calendar and manage the events on that calendar. It cannot see, read or change any other calendar in the account, and it does not access email, contacts, files or any other Google data.

How the data is used

The only use is to add, update and remove events on the calendar the app created, so the household sees its own plans and reminders. Event details come from information the household chose to give the app.

Where data is stored

The app runs on the household's own computer. Event records and the sign-in token are stored there. No data is sent to the app's developer or to any other server, apart from Google Calendar itself.

Sharing

Google user data is never sold, shared with third parties, used for advertising or used to train AI models.

Removing access

Access can be removed at any time from the Google Account page under Security, Third-party apps. Deleting the app's calendar removes all of its events.

Contact

Questions can be raised through the issues page of this site's GitHub repository.
